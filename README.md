# AIPAD Project

Fair Prediction of adverse outcomes after lower limb revascularization using French nationwide medico-administrative data.
A central repository for reusable health data resources and research tools used in AIPAD Project.

## Data source
This project uses data from **French National Health Data System (SNDS)**

Access to SNDS data is regulated by French legislation and cannot be redistributed.

## Available Resources

### Medical Coding Systems
- ICD-10 diagnosis codes
- CCAM procedure codes
- GHM classifications
- LPP medical device codes
- ATC drug classifications

### Data Dictionaries
- PMSI variable dictionaries
- SNDS variable dictionaries
- Derived variables and study-specific definitions

### Research Utilities
- R functions
- SQL scripts
- Cohort definitions
- Outcome definitions
- Data preprocessing pipelines

### Documentation
- Coding guides
- Variable definitions
- Methodological notes
