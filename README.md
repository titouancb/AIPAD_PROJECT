# AIPAD Project

A central repository for reusable health data resources and research tools used in AIPAD Project.

Fundings : Grant from Inserm and the French Ministry of Health in the context of MESSIDORE 2023 call operated by IReSP - AAP-2024-MSDR-365849 


## Contents

### Medical Coding Systems
- ICD-10 diagnosis codes
- CCAM procedure codes
- GHM classifications
- LPP device codes
- ATC drug classifications

### Data Dictionaries
- PMSI variable dictionaries
- SNDS variable dictionaries
- Derived variables and study-specific definitions

### Research Utilities
- R functions
- SQL scripts
- Cohort definitions
- Outcome definitions
- Data preprocessing pipelines

### Documentation
- Coding guides
- Variable definitions
- Methodological notes
